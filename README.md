# TEXT1-AHK
# TEXT1NEW.ahk

Скрипт добавляет сочетания клавиш на основе Caps Lock. Caps Lock отключён как обычная клавиша и используется как модификатор.

## Требования

- AutoHotkey v1. Скрипт использует синтаксис версии 1 и не совместим с AutoHotkey v2.
- Для запуска Obsidian нужен файл `C:\Program Files\Obsidian\Obsidian.exe`.
- Скрипт расположен в папке автозагрузки Windows и запускается при входе в систему. "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup"

## Навигация

| Сочетание | Действие |
|---|---|
| Caps+F | Влево |
| Caps+G | Вправо |
| Caps+R | Вверх |
| Caps+V | Вниз |
| Caps+U | Вверх на 5 строк |
| Caps+N | Вниз на 5 строк |
| Caps+Left Alt | На слово влево |
| Caps+Space | На слово вправо |

## Текст и строки

| Сочетание | Действие |
|---|---|
| Caps+Q | Удалить от курсора до начала строки |
| Caps+E | Удалить от курсора до конца строки |
| Caps+A | Выделить строку |
| Caps+D | Удалить строку |

## Приложения и системные действия

| Сочетание | Действие |
|---|---|
| Caps+S | Открыть инструмент «Ножницы» Windows |
| Caps+L | Ввести почту, например `sviraka@gmail.com` |
| Caps+' | Вставить текущие дату и время в формате `ГГГГ.ММ.ДД ЧЧ:ММ` |
| Caps+W | Свернуть активное окно |
| Caps+C | Найти выделенный текст в Google в браузере по умолчанию |
| Caps+O | Запустить Obsidian |
| Caps+P | Отправить Right Ctrl+Delete для Discord |
| Caps+M | Включить или выключить системный звук |
| Caps+плюс/равно | Переключить режим «Поверх остальных окон» |

## Символы

| Сочетание | Символ |
|---|---|
| Caps+1 | `!` |
| Caps+2 | `@` |
| Caps+3 | `#` |
| Caps+4 | `;` |
| Caps+6 | `:` |
| Caps+7 | `?` |
| Caps+8 | `*` |
| Caps+9 | `(` |
| Caps+0 | `)` |
| Caps+[ | `[` |
| Caps+] | `]` |
| Caps+, | `<` |
| Caps+. | `>` |
| Caps+/ | `/` |
| Caps+обратный слеш | `|` |
| Caps+тильда | `~` |
| Caps+- | `—` |

Клавиша Caps+5 в текущем скрипте не назначена.

## Русские символы через Alt+Ctrl

- Alt+Ctrl+S — `ы`, с Shift — `Ы`
- Alt+Ctrl+E — `ё`, с Shift — `Ё`
- Alt+Ctrl+клавиша VK_DE — `э`, с Shift — `Э`
- Alt+Ctrl+клавиша VK_DD — `ъ`, с Shift — `Ъ`
- Alt+Ctrl+T — `ё`, с Shift — `Ё`
- Alt+Ctrl+M — `ъ`

## Примечания

- Caps+P отправляет сочетание клавиш; для отключения микрофона в Discord оно должно быть назначено в настройках Discord.
- Caps+C использует буфер обмена для чтения выделенного текста, а затем восстанавливает его.
- После изменения файла перезапустите скрипт через значок AutoHotkey в области уведомлений Windows.
